# TechPulse FY-26 — CS1 AUTOSAR HLD Intelligence Assistant

Student: Student · Institution · IT · PRN STUDENT_PRN

The project is under `project/`, with the prescribed eight submission folders. It provides synthetic HLD ingestion, FAISS retrieval, local Qwen/BGE inference, cited outputs, architecture extraction, revision comparison, deterministic candidate findings, review audit records and a fixed evaluation set.

See `Documentation/SETUP_WINDOWS.md` for commands. See `Evaluation_Results/` for measured outputs and failures. `baseline` means TF-IDF plus extractive answers; `local` means Sentence Transformers BGE embeddings plus Qwen GGUF inference; optional `ollama` requires its own run. No silent fallback between modes.

This is a single-user synthetic teaching prototype. It does not certify AUTOSAR compliance. Review identity is self-reported, project filtering is not enterprise authorization, and automated citation checks do not establish entailment.

Documents were prepared with ChatGPT/Codex assistance. Student review was confirmed on 07/10/2026. Signed student documents are supplied in the private submission copy; faculty approval must be evidenced by a signed faculty record. Proprietary reference files and model weights are deliberately excluded from Git.
